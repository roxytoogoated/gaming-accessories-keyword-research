# Gaming Accessories Keyword Research — India

## Project Overview
This beginner SEO project focuses on keyword research for gaming mice in the Indian market.

## Tools Used
- Google Keyword Planner
- Google Search
- Microsoft Excel / Google Sheets

## Work Completed
- Collected keyword ideas and search-volume data.
- Selected seven relevant gaming mouse keywords.
- Classified keywords by type, search intent, and keyword length.
- Recorded observations from Google's search engine results pages (SERPs).
- Assigned preliminary keyword priorities with reasons.

## Project Status
Initial keyword research and analysis completed.

## Next Steps
- Learn keyword clustering.
- Develop a keyword-based content plan.
- Explore on-page SEO fundamentals.

## Learning Objective
To understand how keyword research supports SEO strategy and content planning.
